# はじめに

Windowsデスクトップ版は`Estimate2/Estimate2.exe`から開きます。初回は事業者名・自分の名前だけを登録し、次回からはログイン画面なしで使えます。既存DBの利用者が複数いる場合は従来のログインが必要です。データは`%LOCALAPPDATA%\Estimate2\estimate2.sqlite3`に保存され、ウィンドウの「ファイル → データをバックアップ」でバックアップできます。

見積管理システムは、個人や小規模チームが、相談内容から見積・受注・請求・入金までを管理するためのサンプルです。ログイン後は見積一覧が開き、仕事場をイメージした「アトリエ」もナビゲーションから利用できます。

## 最初の操作

ブラウザー開発版を空DBで初めて起動した場合は、「最初の管理者を登録」が表示されます。事業者名・屋号、自分の名前、半角英数字のユーザー名、12文字以上のパスワードを入力し、「登録してはじめる」を押してください。登録と同時にログインします。次回からはユーザー名とパスワードでログインします。この登録画面は初回だけです。

1. デスクトップ版を開きます。空DBでは初期設定します。ブラウザー開発版では初回登録またはログインします。
2. 「取引先」で顧客を登録します。
3. 「アトリエ」の「新しい案件をはじめる」、または「案件管理」から「案件を作成」を押します。
4. 案件に要望を登録し、今回引き受ける範囲を整理します。
5. 案件から見積書を作成し、発行します。
6. 顧客との確認後、受注を登録します。
7. 請求書を発行し、入金を確認して記録します。

デモ環境では `solo` が承認なしの個人事業主用アカウントです。`staff` → `manager` → `director` は、多段階承認の確認用です。デモのパスワードは `demo1234` です。本番運用用の認証・配備は別途整備が必要です。

## 画面の使い分け

| 画面 | できること |
| --- | --- |
| アトリエ | 最近の案件ノート、仕事の状況、次の一歩メモ、書類の引き出し |
| 案件管理 | 相談の整理、要望の履歴、関連する見積・受注・請求の確認 |
| 見積書 | 見積の作成、承認申請、発行、PDF取得 |
| 受注管理 | 受注・納品・取消の記録 |
| 請求・入金 | 請求書発行、未入金確認、入金の記録 |
| 操作マニュアル | 記事の検索、目次、Markdownで記事を保存 |

画面上部の「データを再読み込み」で最新情報を取得できます。狭い画面ではメニューがアイコン表示になります。

## アトリエの見方

「デスクをひらく」で案件一覧、「次の一歩メモ」で承認待ち・確認事項・作成途中の見積・未入金の確認場所へ進めます。カードから案件ノートを開き、タブで「ダッシュボード」「要望のメモ」「案件の概要」「添付ファイル」を切り替えます。

案件ノートは右上の×またはEscで閉じます。入力を変更したフォームがある場合は、閉じる前に確認が表示されます。タブ切り替えでは入力を保持しますが、自動保存ではないので各フォームの保存ボタンを押してください。

件数・金額は閲覧できるデータの集計です。「動いている案件」は相談中から検収待ちまで、「作成途中の見積」は下書き・差戻し、「請求済み・未入金」は発行済みで入金の記録がない請求です。状態の目盛りは案件の段階を表し、作業の完了率ではありません。

## この試作版の範囲

顧客へのメール送信、顧客自身の承認画面、電子契約、工数集計、分割請求、銀行連携、発注・外注管理、SSOは未対応です。案件の外部リンクから、普段使っている開発管理ツールを開けます。
