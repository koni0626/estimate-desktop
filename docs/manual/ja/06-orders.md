# 受注を登録する

## 合意した版から受注する

1. 発行済みの見積を開きます。
2. 顧客と合意した版を選びます。
3. 受注登録で受注日、納品予定日、メモを入力して保存します。

受注は発行済みの見積から作成します。受注時の版と金額を保持するため、その後の改訂版で金額が自動変更されることはありません。一つの見積には一つの受注を登録できます。

顧客とのやり取りに合わせて、見積詳細の営業状態を未提出・提出済み・失注に変更できます。受注があると受注済みとして表示されます。

## 納品と取消

「受注管理」から受注の詳細を開き、納品したら状態を更新します。案件の進捗は別に更新してください。

受注を取り消す場合は理由をメモに記録します。有効な請求書がある受注は取り消せません。請求書の状態を先に確認してください。取消済み受注を戻す場合も、当初と同じ見積の版を使用します。

## 追加の受注

追加要望は案件内で別の見積を作成・発行し、その見積から受注します。案件には複数の見積と受注をまとめられます。

次は [請求と入金を管理する](07-invoices.md) を確認します。
