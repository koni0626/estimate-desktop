# 見積書を承認する

## 会社ごとの設定

会社管理者が「会社設定」で、承認なし、または多段階承認を選択します。多段階承認では段階名と承認者、必要に応じて代理承認者を設定します。課長→部長などの順序で、最大10段階です。

個人で利用する場合は承認なしで発行できます。

## 申請と承認

担当者が見積詳細で「承認を申請」を押します。承認者は「承認待ち」から対象を開き、内容を確認して承認します。次の段階へ順番に進み、全段階が完了すると承認済みになります。担当者が最後に見積書を発行します。

申請時点の承認ルートを保存します。後から会社設定を変更しても、申請済みのルートには反映されません。同じ人の重複承認や自己承認は行えません。

## 差戻しと修正

修正が必要なら承認者が理由を添えて差し戻します。担当者は見積を編集して再申請します。申請中は申請を取り下げて修正でき、承認済みは「承認を解除して編集」で編集に戻せます。

要望側を変更しても申請した見積の対象要望は変わりません。内容を見積にも反映したい場合は、編集できる状態へ戻して「現在の版を取り込む」を使い、再申請してください。
