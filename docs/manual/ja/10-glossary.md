# 用語集

| 用語 | このシステムでの意味 |
| --- | --- |
| 案件 | 一つの仕事に関する要望と見積・受注・請求をまとめる単位 |
| 要望 | 顧客の相談や必要な機能。登録だけでは対応の約束にならない |
| 完了条件 | 何を満たせば対応完了とするかの具体的な基準 |
| 対象範囲 | 今回の対象・対象外・保留・追加見積などの整理 |
| 合意記録 | 顧客と確認した相手・方法・内容を担当者が残す記録 |
| 要望の版 | 要望の保存や合意記録ごとに増える履歴番号 |
| 見積の改訂版 | 発行済みの見積を修正する新しい版。元の版も残る |
| 対象要望 | 見積に選択した要望の特定の版の記録 |
| 承認 | 見積を発行する前の自社内での確認 |
| 受注 | 顧客と合意した発行済み見積の版から作る売上の記録 |
| 入金記録 | 実際の全額入金を確認した後の手動記録 |
| 無効化 | 発行済み請求書を履歴に残したまま有効な請求から外す操作 |
