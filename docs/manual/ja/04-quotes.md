# 見積書を作成・発行する

## 案件から見積を作る

1. 案件詳細の「案件の見積を作成」を押します。
2. 「案件と対象の要望」で見積に含める要望を選択します。
3. 件名、有効期限、明細の数量・単価・税率を入力します。
4. 納期、支払条件、備考を確認して下書きを保存します。

要望を選択しても、金額や明細は自動作成されません。見積に取り込んだ要望の内容は詳細画面の「この見積の対象要望」で確認できます。要望の詳細や合意記録はPDFには出力しません。顧客へ提示する対象範囲は明細や備考にも記載してください。

「見積書」画面から作成するときも案件を選択できます。案件に紐付けずに作成することもできます。一度保存した見積の案件は変更できません。案件と見積の取引先は同じである必要があります。

## 金額を確認する

数量は小数3桁、単価は小数2桁まで入力できます。明細金額は円単位で四捨五入し、税率ごとの合計から税額を計算して切り捨てます。税率は0%、8%、10%から選択します。

## 発行とPDF

承認なしの会社は「見積書を発行」を押します。承認ありの会社は「承認を申請」し、全段階の承認後に発行します。発行時に番号が付きます。

発行前は「PDFプレビュー」、発行後は「PDFをダウンロード」で内容を確認できます。発行済みPDFは保存された内容を再取得します。会社住所や印鑑を変更しても、過去の発行済みPDFは変わりません。

## 修正と追加見積

発行済みの修正は「改訂版を作成」で新しい版を作ります。元の版は残り、版の選択欄から確認できます。要望の選択も引き継ぎますが、自動で最新版には更新しません。

追加料金の見積は、案件から別の見積を新規作成し、「追加見積」の要望を選択してください。同じ見積の改訂版は、新しい受注を増やす用途には使いません。

「複製」は独立した見積を作ります。案件と要望の紐付けは引き継ぎません。

詳しくは [承認](05-approvals.md)、[受注](06-orders.md) を参照してください。
