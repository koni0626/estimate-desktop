# 案件を管理する

案件は、一つの仕事について、要望と見積・受注・請求をまとめる場所です。

## 案件を作成する

1. アトリエの「新しい案件をはじめる」、または「案件管理」→「案件を作成」を押します。
2. 案件名と取引先を入力します。
3. 目的・背景、目標納期、開発管理の外部リンクを必要に応じて入力します。
4. 「案件を保存」を押します。

取引先がない場合は、先に「取引先」で登録してください。案件の担当者と部・課は作成者から設定されます。部・課がない個人事業主でも利用できます。

## 一覧で探す

案件名・取引先・目的で検索し、状態で絞り込めます。「未整理・確認事項あり」は、対象範囲が未整理、または確認事項が入力されている要望の件数です。同じ要望は1件と数えます。

カードを押すと案件ノートがパネルで開きます。最初のページは「ダッシュボード」です。「案件の概要」で目的・納期・受注額・未入金額を確認できます。閉じるボタンまたはEscで元の一覧・アトリエへ戻れます。

## 相手先の会社情報を登録する

「案件を作成」または「案件を編集」で、会社名・屋号（取引先）、相手先の担当者名、法人番号を指定します。会社名・屋号の登録・変更は「取引先」で行います。新規案件では取引先に登録された担当者名を初期入力し、案件に合わせて変更できます。

担当者名と法人番号は案件ごとに保存し、取引先マスターや作成済み書類には反映しません。法人番号は任意の半角数字13桁です。T付きの登録番号は入力しません。番号の実在確認・自動検索は行いません。個人事業主など番号がない相手先では空欄にできます。既存案件の未登録項目は「未登録」と表示します。

ダッシュボードの「相手先の会社情報」で3項目を確認できます。

## 案件の進捗を変更する

案件を開き「案件を編集」から状態を変更します。相談中、見積中、進行中、検収待ち、完了、保留、中止を選択できます。受注や請求の操作による自動変更は行いません。

一度でも見積を作成した案件では、取引先を変更できません。別の顧客の仕事は新しい案件に登録してください。案件の削除や担当者変更は、この試作版では行えません。

## 関連する書類を確認する

「ダッシュボード」タブに、この案件で作成した見積と、その見積から作られた受注・請求書が表示されます。クリックして詳細画面を開けます。

上部に見積額・受注額・請求済み額・未入金額と入金済み額を表示します。見積額は各見積の最新版の合計で、下書き・失注も含む参考金額です。請求済み額は発行済みと入金済みの合計です。各段階の金額は合算しません。下部は見積ごとに受注・請求を並べ、受注元の版と支払期限、入金日も確認できます。期限を過ぎた未入金の請求は上部にも表示します。

受注額は取消以外の受注合計、未入金額は発行済みで入金記録のない請求書の合計です。どちらも税込で、下書き請求書や無効な請求書は未入金額に含みません。

案件作成以前の見積はそのまま利用できますが、既存の見積を案件へ移す機能はありません。案件から新しい見積を作成してください。

## 資料を添付する

1. 案件ノートの「添付ファイル」タブを開きます。
2. ファイルを複数選び、点線の枠へドラッグ＆ドロップします。「ファイルを選ぶ」ボタンからも追加できます。
3. 自動で添付が始まり、各ファイルに「保存済み」と表示されたら完了です。
4. 保存した資料の「保存」ボタンで、ファイルをダウンロードします。

PDF、画像、Excel、ZIP、テキストなどを添付できます。1ファイル10MB、1案件30件・合計100MBまでです（1MB = 1,024 × 1,024バイト）。空のファイルは添付できません。フォルダーはZIPにまとめてください。

同名のファイルも別の資料として保存されます。登録日・登録者・容量を確認して利用してください。添付できなかった項目は理由が表示され、「失敗したファイルを再試行」でやり直せます。添付処理中は画面を閉じずに完了を待ち、途中で離れた場合は戻って一覧を確認してください。

不要な資料はごみ箱ボタンから削除できます。確認画面で「削除する」を押した後は元に戻せません。「残す」でキャンセルできます。案件を編集できる担当者・管理者だけが添付・削除でき、閲覧権限があるメンバーはダウンロードできます。

添付ファイルは案件内部の共有資料です。顧客への自動送信や、見積書・請求書PDFへの埋め込みは行いません。

続いて [要望と合意を記録する](03-requests.md) を確認します。
