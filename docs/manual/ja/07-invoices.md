# 請求と入金を管理する

## 請求書を作成する

1. 受注詳細から請求書を作成します。
2. 発行日、取引日、支払期限、振込先、必要な登録番号、備考を確認します。
3. 下書きを保存し、内容を確認して請求書を発行します。
4. PDFをダウンロードして、普段の方法で顧客へ送付します。

明細と金額は受注時に合意した見積の版から引き継ぎます。この試作版は一つの受注に一つの有効な請求書を作る方式で、分割請求や一部入金には対応していません。請求書専用の承認フローやメール送信はありません。

## 入金を記録する

実際の入金を確認後、請求書の詳細から入金日とメモを入力して記録します。全額の入金として扱います。未来の日付は指定できません。

「請求・入金」で未入金や支払期限超過の請求書を確認できます。銀行口座との自動連携はありません。

## 記録を訂正する

誤った入金記録は理由を入力して取り消します。発行済みの請求書自体を訂正する場合は、未入金の状態で理由を付けて無効化し、受注から新しい請求書を作成します。発行番号は新しいものになります。

発行済みPDFは変更されず、履歴に残ります。削除や番号の使い回しは行いません。
