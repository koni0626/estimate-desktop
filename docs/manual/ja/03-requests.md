# 要望と合意を記録する

要望を登録するだけでは、対応を引き受けたことにはなりません。内容の整理と、顧客と確認した合意を分けて記録します。

## 要望を登録する

案件を開き「要望を追加」を押します。要望名、内容、完了条件、確認事項、優先度、対象範囲を入力して「要望を保存」を押します。

例：要望名「空き時間から予約できる」、完了条件「空き枠のみ選択でき、予約完了時に確認画面を表示する」、確認事項「キャンセル期限は何日前か」。

## 対象範囲を整理する

| 対象範囲 | 用途 |
| --- | --- |
| 未整理 | 相談段階。まだ扱いを決めていない |
| 今回の対象 | 今回の見積に含める候補 |
| 対象外 | 今回は対応しない |
| 保留 | 判断を後回しにする |
| 追加見積 | 追加料金を含めて別途確認する |

見積に選択できるのは「今回の対象」「追加見積」です。確認事項が解決したら、要望を編集して確認事項の欄を空にして保存します。以前の内容は変更履歴で確認できます。

## 合意を記録する

1. 対象範囲を「今回の対象」または「追加見積」にします。
2. 完了条件を入力して保存します。
3. メールや打ち合わせで顧客に内容を確認します。
4. 要望の「合意を記録」を押します。
5. 合意相手、日付、確認方法を入力して保存します。

状態は「合意済み」になります。記録者と記録時刻は自動で残ります。これは担当者による手動の記録で、顧客の電子署名や自動通知ではありません。合意後は編集から「対応中」「顧客確認」「完了」を記録できます。

## 合意後に変更が出たとき

件名、内容、完了条件、対象範囲を変更するときは変更理由を入力します。保存すると現在の合意は解除され、状態が「相談中」に戻ります。以前の合意は「変更履歴」に残ります。変更した内容を再確認してから新たな合意を記録してください。

追加の機能は別の要望として「追加見積」で登録すると、当初の範囲と区別しやすくなります。

## 見積に取り込んだ内容

要望の保存ごとに版が増えます。見積は選択した版の内容を保持するため、後から要望を変更しても、その見積の記録は自動更新されません。見積編集で「現在の版を取り込む」を押すと、新しい内容を選び直せます。
