# 会社・取引先・メンバー設定

## 取引先を登録する

「取引先」で会社名・氏名、担当者、住所、メールアドレスを登録します。見積作成時に選択できます。取引先を更新しても、発行済みの書類には反映されません。

## 会社と印鑑を設定する

会社管理者が「会社設定」で、会社名、住所、電話番号、振込先、登録番号、承認方式を設定します。

印鑑画像は任意です。PNGまたはJPEG、2MB以内、縦横10〜2,000ピクセルの画像を登録できます。会社の初期設定と見積ごとの選択で表示を切り替えます。画像を差し替えたり無効化しても、過去の発行済みPDFは変わりません。

印鑑画像の表示は電子署名機能ではありません。顧客への提出形式は相手と確認してください。

## メンバーと組織

会社管理者が「メンバー・組織」から部・課とメンバーを登録します。部・課を使わない運用もできます。

| 権限 | 案件・見積の閲覧範囲 | 変更できる範囲 |
| --- | --- | --- |
| 会社管理者 | 自社全体 | 自社全体 |
| 部管理者 | 自分の部 | 自分の部 |
| 課管理者 | 自分の課 | 自分の課 |
| 一般担当者 | 自分の課。所属なしは自分の担当分 | 自分の担当分 |

会社をまたいでデータは表示されません。案件から作る見積は案件の担当者と所属を引き継ぎます。承認者に指定された場合は、通常の閲覧範囲外でも対象の見積の版を確認できますが、それだけで案件全体の閲覧権限が付くことはありません。

## 操作履歴

会社管理者は「操作履歴」で会社内の操作記録を確認できます。要望の具体的な内容や合意の過去の状態は、案件内の「変更履歴」で確認してください。
