# 見積管理システム 設計書セット

この独立プロジェクトは`E:\app\estimate-desktop`にあり、Windowsインストーラーの設計は[08-installer-design.md](08-installer-design.md)に記す。

利用者向けの正規構成はWindowsデスクトップ版です。個人利用ではパスワード入力を求めず、初回に事業者名・表示名を登録した後は自動で仕事場を開きます。[デスクトップ版の設計](07-desktop-design.md)と[起動・バックアップ手順](../desktop.md)を先に参照してください。ソース開発時は従来のブラウザー版も起動できます。実行版ZIPは展開してEXEを起動でき、ソースからの再現・ビルドにはPython 3.14とNode.jsが必要です。

版 1.0 / 2026-09-23

この設計書の対象は、`E:\app\estimate-desktop` に同梱した**動作するローカル実装**です。会社・部・課ごとの見積管理、任意の順次承認、PDF発行を中心に、案件・要望、受注、請求、全額入金確認までを含みます。個人事業主は部・課と承認経路を作らず利用できます。

さらに [実装対応表](implementation-map.md) に、要件・コード・テストの位置をまとめています。画面操作は [操作マニュアル](../manual/ja/01-first-steps.md) を参照してください。作業フォルダーの `docs/specification.md` などは開発過程の検討資料で、配布ZIPには含めません。既存実装の説明とコードに相違があればコードを確認し、ソースなしの再実装では下記の再実装仕様書を優先します。

ソースコードを渡さずCodexで新規実装する場合は、[Codex向け再実装仕様書](06-codex-rebuild-spec.md) を最初に読み、この設計書セットと `docs/manual/ja` を一緒に渡してください。HTTPの全経路・入力型は [OpenAPI定義](contracts/openapi.json)、DBの全テーブル・制約は [SQLiteスキーマ](contracts/sqlite-schema.sql) に含めています。配布用の設計書だけのZIPは `scripts/package_spec.py` で生成できます。

## 提供物と正確な位置づけ

これは学習・評価用の**ローカル動作サンプル**です。画面、API、SQLiteマイグレーション、テスト、PDF用日本語フォントとライセンスを含みます。空DBの初回だけ事業者と管理者を本人が登録できます。オプションで投入できるサンプル会社・ユーザー・取引先は架空です。SSO、初回以外の新規事業者セルフ登録、メール送信、決済、発注・外注費、部分入金、会計連携、負荷試験、外部公開のための監視・バックアップは含みません。

設計書に「実装済み」と書いた機能はソース上に対応箇所があり、[検証・運用](05-verification-operation.md) の手順で再現できます。「将来拡張」は動作する機能として販売しません。Windows実行版はZIPを展開してEXEを起動できます。ソースから再現・ビルドする場合はPython 3.14、Node.jsと依存パッケージの導入が必要です。SQLiteはPythonに同梱されています。
